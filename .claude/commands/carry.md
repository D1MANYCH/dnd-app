description: Handoff summary before /clear — what is done, file state, next step; optionally saved to the plan file
argument-hint: [X-N]  (пусто — текущая работа)
---
Аргумент: $ARGUMENTS.

Выдай резюме переноса, **не больше 5 строк**, по форме:

```
Сделано: …
Состояние файлов: … (незакоммиченные правки — из `git status --short`)
Следующий шаг: …
Открытые вопросы: … (или «нет»)
```

Затем, если аргумент назвал фазу или из контекста ясен активный план: допиши это
резюме в конец соответствующего `project_*_plan.md` в
`~/.claude/projects/.../memory/` под заголовком `### Перенос <дата>` и скажи одной
строкой, в какой файл записал. Если план не определяется — не угадывай, просто
покажи резюме.

Ничего не коммить. В конце предложи `/clear`.
